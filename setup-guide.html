Together Ledger 서버 이전 가이드

SQLite → Neon(PostgreSQL) 로컬 테스트 → Render 배포

① Neon DB 세팅
CREATE TABLE IF NOT EXISTS users (
  sync_id       TEXT   PRIMARY KEY,
  password_hash TEXT   NOT NULL,
  created_at    BIGINT NOT NULL
);

CREATE TABLE IF NOT EXISTS devices (
  id            SERIAL PRIMARY KEY,
  sync_id       TEXT   NOT NULL REFERENCES users(sync_id),
  android_id    TEXT   NOT NULL,
  device_name   TEXT,
  registered_at BIGINT NOT NULL,
  last_seen_at  BIGINT NOT NULL,
  UNIQUE (sync_id, android_id)
);

CREATE TABLE IF NOT EXISTS categories (
  id         TEXT    PRIMARY KEY,
  sync_id    TEXT    NOT NULL REFERENCES users(sync_id),
  name       TEXT    NOT NULL,
  is_income  INTEGER NOT NULL,
  updated_at BIGINT  NOT NULL,
  is_deleted INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE IF NOT EXISTS transactions (
  id                 TEXT    PRIMARY KEY,
  sync_id            TEXT    NOT NULL REFERENCES users(sync_id),
  category_server_id TEXT,
  content            TEXT    NOT NULL,
  time_stamp         TEXT    NOT NULL,
  amount             INTEGER NOT NULL,
  asset_type         TEXT    NOT NULL,
  is_income          INTEGER NOT NULL,
  updated_at         BIGINT  NOT NULL,
  is_deleted         INTEGER NOT NULL DEFAULT 0
);
4개 테이블이 모두 생성되면 OK.
② 로컬 서버 .env 설정
DATABASE_URL=postgresql://user:password@ep-xxx...neon.tech/neondb?sslmode=require
③ 패키지 설치 및 로컬 테스트
npm install
npm start
콘솔에 Together Ledger 서버 실행 중: http://localhost:3000 이 뜨면 OK.
오류가 나면 DATABASE_URL이 올바른지 확인.
④ Render 배포 로컬 테스트 완료 후
서버 코드(together-ledger-server/)가 별도 레포이거나 모노레포 서브폴더에 있다면 Root Directory를 together-ledger-server로 지정.
Build Command : npm install
Start Command : npm start
Node Version  : 20 이상 (Environment 탭에서 설정)
DATABASE_URL           = (Neon connection string 그대로)
JWT_SECRET             = (긴 랜덤 문자열, 로컬과 같아도 됨)
MAX_ACCOUNTS_PER_DEVICE = 5
PORT는 Render가 자동으로 주입하므로 등록 불필요.
